„Система за управление на задачи със срокове и приоритети“

1. Обща информация

Тип проект: Проектно задание по производствена практика Ученик: Валентин Николенко Клас: XI Г клас Специалност: Приложно програмиране Цел: Разработка на система за ефективно управление на задачи с приоритети, срокове и статус на изпълнение.

2. Кратко описание на проекта

Проектът има за цел да се разработи уеб-базирана система за управление на задачи (Task Management System), която позволява на потребителите да създават, преглеждат, редактират и изтриват задачи, както и да проследяват тяхното изпълнение. Всяка задача разполага със срок за изпълнение, приоритет и статус. Системата предоставя възможности за филтриране, търсене и коментиране на задачи, както и управление на потребителски профили.

3. Функционални изисквания

Системата трябва да предоставя следните функционалности:

3.1 Управление на потребители

· Регистрация на нови потребители.

· Вход (login) и изход (logout) от системата.

· Управление и редактиране на потребителски профил.

· Роли на потребители (напр. потребител, администратор).

3.2 Управление на задачи

· Създаване на нови задачи.

· Редактиране на съществуващи задачи.

· Изтриване на задачи.

· Отбелязване на задачи като завършени / незавършени.

· Преглед на списък с всички задачи.

3.3 Приоритети и срокове

· Задаване на приоритет (нисък, среден, висок).

· Задаване на краен срок за изпълнение.

· Подреждане на задачите по приоритет и/или срок.

3.4 Допълнителни функционалности

· Добавяне на коментари към всяка задача.

· Филтриране на задачи по статус, приоритет, срок.

· Търсене на задачи по ключови думи.

4. Технически изисквания

4.1 Използвани технологии

· Backend: Java (Spring Boot или еквивалентна рамка).

· Frontend: HTML5, CSS3, JavaScript.

· База данни: Релационна база данни (MySQL, PostgreSQL или еквивалентна).

4.2 Архитектура

· Трислойна архитектура:

o Presentation Layer (UI / Frontend)

o Business Logic Layer (Backend логика)

o Data Access Layer (работа с база данни)

4.3 API и сигурност

· Изграждане на RESTful API за комуникация между frontend и backend.

· Реализация на механизми за автентикация и авторизация.

· Защита на чувствителните данни.

5. Допълнителни изисквания

· Реализация на интуитивен и удобен потребителски интерфейс.

· Възможност за бъдещо разширяване и мащабируемост на системата.

· Пълно тестване на основните функционалности.

6. Тестване

· Integration тестове за API и връзката с базата данни.

· Проверка за коректна работа при различни сценарии.

7. Планиране и изпълнение

· Изготвяне на план за разработка с ясно дефинирани етапи:

1. Анализ и проектиране

2. Разработка на backend

3. Разработка на frontend

4. Интеграция

5. Тестване и отстраняване на грешки

· Определяне на срокове за всяка фаза.

· Разпределяне на задачите между членовете на екипа (ако има такъв).

· Използване на инструменти за управление на проекти (напр. Jira, Trello, Git).
